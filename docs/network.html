Comparing scenarios (bar chart of discrete options, not a line)

These four configurations are discrete, mutually exclusive choices, not points on a continuum — a line chart would wrongly suggest you can interpolate between them. One bar per scenario, sorted best-to-worst, answers the actual question directly.

Why: baseline vs. the best alternative (side-by-side maps)

This decision is fundamentally about geographic coverage, more than either of the other two dashboards — so unlike the cost dashboard, a spatial view isn't optional here, it's the main evidence. Each city is plotted over a real France outline and colored by which warehouse it's assigned to, so the coverage shift is visible at a glance instead of requiring you to read coordinates. The warehouse city itself is drawn as a bigger, black-outlined triangle inside its own color group — so you can see both "which warehouse serves this city" (color) and "which point is the actual warehouse" (shape) in the same view.
