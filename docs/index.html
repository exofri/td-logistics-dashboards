Same network, three different decisions

One real French logistics network (3 existing warehouses, 20 real French cities, distances computed from real coordinates) — three dashboards, each built for a different person and a different decision, each with a deliberately different chart-choice argument. See TD_5_DELIVERY_MANUAL_dashboard_design.md for the full reasoning behind each choice.

Sustainability / CSR manager

CO2 dashboard

Which routes should we prioritize to cut network CO2? Ranked bar chart + a spatial scatter, because the decision is about both "how much" and "where."
Logistics / operations manager

Cost dashboard

Where does cost concentrate — transport or storage — per warehouse? A stacked bar (not a bar, not a pie) plus an exact-figures table, because the decision is about which lever to pull.
Strategic / network planning manager

Network dashboard

Should we open a warehouse in Bordeaux or Marseille, or close Lille? A discrete-scenario bar chart plus side-by-side maps, because this decision is fundamentally geographic.
